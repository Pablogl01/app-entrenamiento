# Fuentes de las texturas

Las cuatro provienen de Wikimedia Commons y se procesan con `scripts/textures.mjs`
(tratamiento idéntico: 1200×900 cover, brillo 0.78, saturación 0.8, WebP ≤80 KB).
La capa de oscurecido `--material-scrim` se aplica en CSS.

| `sand.webp` | File:Rippled wavy beach sand seamless ground texture.jpg | CC0 |
| `neutral.webp` | File:Sawn limestone texture.jpg | Dominio público |
